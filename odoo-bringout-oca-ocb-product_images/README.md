# Product Images


Automatically set product images based on the barcode
=====================================================

This module integrates with the Google Custom Search API to set images on products based on the
barcode.
    

## Installation

```bash
pip install odoo-bringout-oca-ocb-product_images
```

## Dependencies

- product
