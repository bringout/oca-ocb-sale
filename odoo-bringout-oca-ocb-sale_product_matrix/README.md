# Sale Matrix


This module allows to fill Sales Order rapidly
by choosing product variants quantity through a Grid Entry.
    

## Installation

```bash
pip install odoo-bringout-oca-ocb-sale_product_matrix
```

## Dependencies

- sale
- product_matrix
