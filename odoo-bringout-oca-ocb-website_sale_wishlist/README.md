# Shopper's Wishlist


Allow shoppers of your eCommerce store to create personalized collections of products they want to buy and save them for future reference.
    

## Installation

```bash
pip install odoo-bringout-oca-ocb-website_sale_wishlist
```

## Dependencies

- website_sale
